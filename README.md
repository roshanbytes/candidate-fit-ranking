# Candidate Fit Ranking

Ranks candidates by how well their job titles match a role's keywords, and re-ranks them each time a reviewer stars one.

## Setup

```bash
conda env create -f environment.yml
conda activate candidate-fit-ranking
python -m pip install -e .
```

Then add the dataset as described in [data/raw/README.md](data/raw/README.md).
